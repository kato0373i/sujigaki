# sujigaki

要求から業務、ユースケース、画面・情報までを一本の筋でつなぎ、業務設計の SSOT として運用するためのツールです。
[RDRA](https://www.rdra.jp/) に準拠したモデルを、ビジネス側とエンジニアの双方が画面上で見て、編集できることを目指しています。

> 現在は要件定義の段階です。実装はまだありません。
